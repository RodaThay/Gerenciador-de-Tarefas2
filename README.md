# 📝 Gerenciador de Tarefas em Java

Um aplicativo simples de lista de tarefas (To-Do List) desenvolvido em Java utilizando a biblioteca Swing para interface gráfica. Este projeto faz parte dos meus estudos no 1º período de Ciência da Computação.

## 🚀 Funcionalidades

- **Adicionar Tarefas:** Captura a entrada do usuário via janelas de diálogo.
- **Remover Tarefas:** Exclui tarefas específicas baseadas no seu índice numérico.
- **Listagem Dinâmica:** Exibe todas as tarefas cadastradas em uma lista numerada e organizada.
- **Interface Gráfica:** Utiliza `JOptionPane` para uma experiência visual fora do console.

## 🧠 Conceitos Aplicados

Durante o desenvolvimento deste projeto, pratiquei conceitos fundamentais de Java e Ciência da Computação, como:
* **ArrayList:** Manipulação de coleções dinâmicas de dados.
* **Estruturas de Controle:** Uso de loops `while` e condicionais `if/else`.
* **Tratamento de Strings:** Formatação de texto e uso de caracteres especiais como `\n`.
* **Conversão de Tipos (Parsing):** Transformação de entradas de texto em números inteiros.

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java
- **Biblioteca:** javax.swing (JOptionPane)
- **IDE:** Visual Studio Code
